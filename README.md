# Viet Bake Shop Sim (src version)

## Cấu trúc

- `index.html`: trang game chính.
- `src/css/style.css`: toàn bộ CSS gốc, giữ nguyên thứ tự.
- `src/js/main.js`: script game chính (bao gồm thư viện/runtime đi kèm trong file gốc).
- `src/js/extra.js`: script bổ sung cuối file gốc.

## Cách chạy

Giữ nguyên cấu trúc thư mục. Mở `index.html` bằng trình duyệt hoặc upload toàn bộ thư mục lên hosting. Nếu hosting yêu cầu trang tĩnh, đặt `index.html` ở thư mục gốc cùng với thư mục `src`.

Lưu ý: các font/ảnh dạng data URI trong file gốc vẫn được giữ nguyên bên trong CSS/HTML, không cần tải thêm asset.
